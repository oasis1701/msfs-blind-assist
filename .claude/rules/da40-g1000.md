# COWS DA40 G1000 display rules

Loaded with the G1000 agent and the display window. Full text of each rule: docs/invariants/da40-g1000.md.

- [DA40G-1] Bezel transport is measured: softkeys, the radio TURNS and the database-acknowledge ENT go over SimConnect; FMS, MENU, ENT, CLR, DTO, FPL, PROC, range, joystick and the radio PUSH go over the Coherent socket. `AS1000_MFD_CLR` has no `_Push` suffix. Full: docs/invariants/da40-g1000.md#da40g-1
- [DA40G-2] A softkey press goes through `ExecuteCalculatorCodeUnique` (the transponder keypad is octal, offset by one, shifting in from the right) and is never silent; the changed-row diff keys on label AND occurrence. Full: docs/invariants/da40-g1000.md#da40g-2
- [DA40G-3] Which display an agent is on is decided by the instrument element (`wtg1000-mfd` vs `wtg1000-pfd`), never by page markup. Full: docs/invariants/da40-g1000.md#da40g-3
- [DA40G-4] Ask the G1000 for its state through `viewService` and the scroll controller, never off a CSS class; its interaction rules come from its own source (`Function.prototype.toString`), and the DOM reader is only the fallback. Full: docs/invariants/da40-g1000.md#da40g-4
- [DA40G-5] The G1000 has two control frameworks (`scrollController.controls[]` and `G1000UiControl`) and a reader walks both; the cursor flag stays on the scroll controller. Full: docs/invariants/da40-g1000.md#da40g-5
- [DA40G-6] A page with an empty key in `pageGroups` (15 of 32) is a stub: left out of the Ctrl+G jump list, but the readout still says "not in this G1000" when the knob lands on it. Full: docs/invariants/da40-g1000.md#da40g-6
- [DA40G-7] A PFD page is a SUBVIEW (`viewService.open(key, true)`) and an MFD page is not; opening one the other way registers it and never shows it. Full: docs/invariants/da40-g1000.md#da40g-7
- [DA40G-8] Typed entry drives `InputComponent.setText`, which runs the aircraft's own search and lookup; read the result back after ~900 ms, never immediately. Full: docs/invariants/da40-g1000.md#da40g-8
- [DA40G-9] The MFD's first FMS-knob turn opens the page selector and the next one moves: never auto-send a second turn; read the selector or menu while it is up, with a 1200 ms read-back settle. Full: docs/invariants/da40-g1000.md#da40g-9
- [DA40G-10] A horizontal EIS gauge carries no number: read the needle's `translateX` (`svg[style*='translateX']`, never `.pointer`) and report the band it sits in. Full: docs/invariants/da40-g1000.md#da40g-10
- [DA40G-11] A blank `.nav-data-bar-page-title` (every NRST page) falls back to the page selector's active entry, never "not shown". Full: docs/invariants/da40-g1000.md#da40g-11
- [DA40G-12] A dash is not glue in the agent's text joiner (brackets, commas and the degree sign are); a G1000 list row is read field by field from its children. Full: docs/invariants/da40-g1000.md#da40g-12
- [DA40G-13] A procedure's leg sequence is read per `.proc-sequence-item`, so the FAF and MAP are separate legs. Full: docs/invariants/da40-g1000.md#da40g-13
- [DA40G-14] The first `querySelector` match is not always the one on screen (the PFD has a hidden stale CAS block first): duplicable elements go through `firstVisible`, and `A.cas()` merges every visible copy. Full: docs/invariants/da40-g1000.md#da40g-14
- [DA40G-15] A G1000 popout dialog is open iff its `opacity` is non-zero; display, visibility and size never change. Full: docs/invariants/da40-g1000.md#da40g-15
- [DA40G-16] A page menu (`*MenuDialog`) is never row-named, and a self-naming value ("X: Y") neither names a row nor takes one's name; checklist selectors go through `A.checklistSelectorSay`. Full: docs/invariants/da40-g1000.md#da40g-16
- [DA40G-17] A field is read with its group box (`groupbox` + `groupbox-title`); the PFD's own windows name their rows, and the ancestor-title fallback runs only when no groupbox was found. Full: docs/invariants/da40-g1000.md#da40g-17
- [DA40G-18] Only five of System Setup's ten boxes have controls and Setup 2 is a stub; the 77 settings are a store spread over pages and softkeys; every page has a MENU and Ctrl+E opens it. Full: docs/invariants/da40-g1000.md#da40g-18
- [DA40G-19] Every agent function `CowsDA40DisplayForm` calls is a by-NAME contract checked by `CowsDA40G1000AgentContractTests` (answer field count, duplicate definitions, renamed functions). Full: docs/invariants/da40-g1000.md#da40g-19
- [DA40G-20] Indentation is not a CAS message: `ExtractCasMessages` starts at `CAS messages:` and ends at the first row outside the block. Full: docs/invariants/da40-g1000.md#da40g-20
- [DA40G-21] Never prefix a per-item state to every announcement: announce a state on its transition, and say "end of the page" when a field-moving turn left the focus where it was. Full: docs/invariants/da40-g1000.md#da40g-21
- [DA40G-22] The display window holds its redraw 2.5 s after the last navigation key so a live list does not re-announce items; feed the CAS watcher and announcers before the hold. Full: docs/invariants/da40-g1000.md#da40g-22
- [DA40G-23] The stock G1000's source is public (`msfs-avionics-mirror`); the aircraft's plugin (`Da40NgMfdPlugin.js`) is not and must be probed. Full: docs/invariants/da40-g1000.md#da40g-23
- [DA40G-24] A read-the-view's-text fallback is a whitelist (`Auth` only); escape a stuck page view with `goPage`, and cancel a Navigraph sign-in rather than leave it running. Full: docs/invariants/da40-g1000.md#da40g-24
- [DA40G-25] The IFR toolkit views (Direct-To, PROC, HoldAt, SelectAirway, FPL constraints) are all read; do not claim altitude constraints or radial intercepts flown end to end until they are. Full: docs/invariants/da40-g1000.md#da40g-25
- [DA40G-26] A SimBrief plan reaches the G1000 only through the Navigraph Flight Plan Catalog (softkey 5 Activate, then the dialog); never add a one-press import macro. Full: docs/invariants/da40-g1000.md#da40g-26
- [DA40G-27] The XLS plugin's pages are `Da40EnginePage`/`Da40ChecklistPage`, the NG's `Da40Ng…`: the agent accepts both, and reads XLS bars back through `DISP_EGT:n`/`DISP_CHT:n`. Full: docs/invariants/da40-g1000.md#da40g-27
- [DA40G-28] A panel.xml `<ShortText>` alert (ROLL, PTCH, PTRM, the servo forces, TRAFFIC, TERRAIN, PULL UP) is never in the CAS window, and its box shows only the top one: `A.shortAlerts()` tests each one's own panel.xml condition (with its 6 s hold) and `A.cas()` adds them, never read off `.warnings-display`; AFCS and PFT are announced rows. Full: docs/invariants/da40-g1000.md#da40g-28
- [DA40G-29] Within one view a knob step speaks only what moved (`CowsDA40DisplayForm.DropRepeatedLead`): a new view, a cursor change and a repeat keep the whole read-back, and the checklist page's own text (`IsChecklistTextView`) is never shortened. Full: docs/invariants/da40-g1000.md#da40g-29
