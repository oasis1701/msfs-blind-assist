# COWS DA40 G1000 display rules

Loaded with the G1000 agent and the display window. Full text of each rule: docs/invariants/da40-g1000.md.

- [DA40G-1] Bezel transport, measured: softkeys, the radio TURNS and the database-acknowledge ENT go over SimConnect; FMS, MENU, ENT, CLR, DTO, FPL, PROC, range, joystick and the radio PUSH go over the Coherent socket. `AS1000_MFD_CLR` has no `_Push` suffix. Full: docs/invariants/da40-g1000.md#da40g-1
- [DA40G-2] A softkey press goes through `ExecuteCalculatorCodeUnique` (the transponder keypad: octal, offset by one, shifting in from the right) and is never silent; a burst gets one read-back, its diff keyed on label AND occurrence, skipping rows that move on their own (`ChangesOnItsOwn`). Full: docs/invariants/da40-g1000.md#da40g-2
- [DA40G-3] Which display an agent is on is decided by the instrument element (`wtg1000-mfd` vs `wtg1000-pfd`), never by page markup. Full: docs/invariants/da40-g1000.md#da40g-3
- [DA40G-4] Ask the G1000 for its state (`viewService`, the scroll controller), never a CSS class; its interaction rules come from its own source (`Function.prototype.toString`); the DOM reader is the fallback. Full: docs/invariants/da40-g1000.md#da40g-4
- [DA40G-5] Two control frameworks (`scrollController.controls[]`, `G1000UiControl`): read both. Cursor: the scroll controller, or Airport Information's `currentPage` focus. Full: docs/invariants/da40-g1000.md#da40g-5
- [DA40G-6] A page with an empty key in `pageGroups` is a stub: out of the Ctrl+G list; the readout says "not in this G1000" when the knob lands on it. Full: docs/invariants/da40-g1000.md#da40g-6
- [DA40G-7] A PFD page is a SUBVIEW (`viewService.open(key, true)`) and an MFD page is not; the other way registers it and never shows it. Full: docs/invariants/da40-g1000.md#da40g-7
- [DA40G-8] Typed entry drives `InputComponent.setText`, which runs the aircraft's own search and lookup; read the result back after ~900 ms, never immediately. Full: docs/invariants/da40-g1000.md#da40g-8
- [DA40G-9] The MFD's first FMS-knob turn opens the page selector, the next moves: never auto-send a second; read the selector or menu while up, with a 1200 ms read-back settle. Full: docs/invariants/da40-g1000.md#da40g-9
- [DA40G-10] A horizontal EIS gauge carries no number: read the needle's `translateX` (`svg[style*='translateX']`, never `.pointer`) and report its band. Full: docs/invariants/da40-g1000.md#da40g-10
- [DA40G-11] A blank `.nav-data-bar-page-title` (every NRST page) falls back to the page selector's active entry, never "not shown". Full: docs/invariants/da40-g1000.md#da40g-11
- [DA40G-12] A dash is not glue in the agent's text joiner (brackets, commas and the degree sign are); a G1000 list row is read field by field from its children. Full: docs/invariants/da40-g1000.md#da40g-12
- [DA40G-13] A procedure's leg sequence is read per `.proc-sequence-item`, so the FAF and MAP are separate legs. Full: docs/invariants/da40-g1000.md#da40g-13
- [DA40G-14] The first `querySelector` match may be hidden (the PFD's stale CAS block): duplicable elements go through `firstVisible`; `A.cas()` merges every visible copy. Full: docs/invariants/da40-g1000.md#da40g-14
- [DA40G-15] A G1000 popout dialog is open iff its `opacity` is non-zero; display, visibility and size never change. Full: docs/invariants/da40-g1000.md#da40g-15
- [DA40G-16] A page menu (`*MenuDialog`) is never row-named, and a self-naming value ("X: Y") neither names a row nor takes one's name; checklist selectors go through `A.checklistSelectorSay`. Full: docs/invariants/da40-g1000.md#da40g-16
- [DA40G-17] A field is read with its group box (`groupbox` + `groupbox-title`); the PFD's own windows name their rows; the ancestor-title fallback runs only with no groupbox. Full: docs/invariants/da40-g1000.md#da40g-17
- [DA40G-18] Five of System Setup's ten boxes have controls, Setup 2 is a stub; the 77 settings are a store spread over pages and softkeys; every page has a MENU (Ctrl+E). Full: docs/invariants/da40-g1000.md#da40g-18
- [DA40G-19] Every agent function `CowsDA40DisplayForm` calls is a by-NAME contract checked by `CowsDA40G1000AgentContractTests` (field count, duplicates, renames). Full: docs/invariants/da40-g1000.md#da40g-19
- [DA40G-20] Indentation is not a CAS message: `ExtractCasMessages` runs from `CAS messages:` to the first row outside the block. Full: docs/invariants/da40-g1000.md#da40g-20
- [DA40G-21] Never prefix a per-item state to every announcement: say a state on its transition, and "end of the page" when a field-moving turn left the focus where it was. Full: docs/invariants/da40-g1000.md#da40g-21
- [DA40G-22] The display window holds its redraw 2.5 s after the last navigation key, never for a new screen or softkey row (`MustRedrawNow`), never past 5 s; the CAS watcher and announcers are fed first. Full: docs/invariants/da40-g1000.md#da40g-22
- [DA40G-23] The stock G1000's source is public (`msfs-avionics-mirror`); the aircraft's plugin (`Da40NgMfdPlugin.js`) is not and must be probed. Full: docs/invariants/da40-g1000.md#da40g-23
- [DA40G-24] A read-the-view's-text fallback is a whitelist (`Auth` only); escape a stuck page view with `goPage`; cancel a Navigraph sign-in, never leave it running. Full: docs/invariants/da40-g1000.md#da40g-24
- [DA40G-25] The IFR toolkit views (Direct-To, PROC, HoldAt, SelectAirway, FPL constraints) are all read; do not claim altitude constraints or radial intercepts flown end to end until they are. Full: docs/invariants/da40-g1000.md#da40g-25
- [DA40G-26] A SimBrief plan reaches the G1000 only through the Navigraph Flight Plan Catalog (softkey 5 Activate, then the dialog); never add a one-press import macro. Full: docs/invariants/da40-g1000.md#da40g-26
- [DA40G-27] The XLS plugin's pages are `Da40EnginePage`/`Da40ChecklistPage`, the NG's `Da40Ng…`: the agent accepts both, and reads XLS bars back through `DISP_EGT:n`/`DISP_CHT:n`. Full: docs/invariants/da40-g1000.md#da40g-27
- [DA40G-28] A panel.xml `<ShortText>` alert (ROLL, PTCH, PTRM, servo forces, TRAFFIC, TERRAIN, PULL UP) is not in the CAS window: `A.shortAlerts()` tests each condition (6 s hold) and `A.cas()` adds them, never read off `.warnings-display`; AFCS and PFT are announced rows. Full: docs/invariants/da40-g1000.md#da40g-28
- [DA40G-29] Within one view a knob step speaks only what moved (`CowsDA40DisplayForm.DropRepeatedLead`); a new view, a cursor change, a repeat and the checklist page's text (`IsChecklistTextView`) keep the whole read-back. Full: docs/invariants/da40-g1000.md#da40g-29
- [DA40G-30] The FMA names its owner (`DescribeFmaChange`): AP's modes or the director's; losing AP with the director up names the director's (the master row says OFF); a drop to off is silent; `FmaModes` drops the vertical target. Full: docs/invariants/da40-g1000.md#da40g-30
- [DA40G-31] A dark screen is not a cleared message: `A.powered` puts `Display power: off` first when `#Electricity` is "off"; `G1000CasWatcher` (`IsDisplayDark`) forgets its messages silently and STAYS baselined, so the power-up's messages speak. Full: docs/invariants/da40-g1000.md#da40g-31
- [DA40G-32] A CAS message that goes is cleared only once gone `G1000CasWatcher.CasClearDebounce.ClearSettleMs`; back inside that, it was never gone and nothing is said. Full: docs/invariants/da40-g1000.md#da40g-32
- [DA40G-33] One-character cells spelling a number are ONE value with the cursor's place (`A.M.digitOf`); placeholder glyphs or a bare unit never label a field; another box's field is never row-named. Full: docs/invariants/da40-g1000.md#da40g-33
- [DA40G-34] The FMA's VS target is unsigned: the `.verticalModeArrow` path gives its direction (rotated 180 = down, `hide-element` = none). Full: docs/invariants/da40-g1000.md#da40g-34
- [DA40G-35] Same owner: the FMA says only the change (`DescribeFmaChange`), an uncaptured armed mode "disarmed"; with no new CAS message it is queued (`ComposeCasSpeech`). Full: docs/invariants/da40-g1000.md#da40g-35
