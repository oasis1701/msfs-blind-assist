# iFly 737 MAX8 rules

Loaded when Claude reads matching code. Background: docs/ifly-737.md. Full text of each rule: docs/invariants/ifly-737.md.

- [IFLY-1] `IFlySdkOffsets`, `IFlySdkFields` and `IFlyKeyCommand` are generated by `tools/ifly-gen/generate_ifly_sdk.py` from the iFly SDK headers: regenerate them, never hand-edit. Full: docs/invariants/ifly-737.md#ifly-1
- [IFLY-2] The iFly is written through its SDK (WM_COPYDATA commands), never MobiFlight or L:var writes; the one exception is the named cockpit-clickspot trigger replays through `SetLVar` (`VC_Automatic_Flight_trigger_VAL`, `VC_Navigation_trigger_VAL`), used only where the SDK command is broken or absent. Full: docs/invariants/ifly-737.md#ifly-2
- [IFLY-3] The spring-loaded electrical momentaries (GRD PWR, ENG and APU generator switches) actuate only through their momentary CLICK commands (Move DOWN = on, Move UP = off), never a SET: a SET moves the switch but never connects or trips. Full: docs/invariants/ifly-737.md#ifly-3
- [IFLY-4] `IFlySdkClient.SendCommand` re-resolves the plugin window with `FindWindowEx` on EVERY send, never caching the HWND: after a sim restart Windows can recycle it, and a send to the recycled window "succeeds" while the aircraft hears nothing. Full: docs/invariants/ifly-737.md#ifly-4
