# HorizonSim 787-9 rules

Loaded when Claude reads matching code. Background: docs/hs787.md. Full text of each rule: docs/invariants/hs787.md.

- [HS-1] The HS787 EFB is intentionally removed: its perf-page inputs reject programmatic value-sets and synthetic keyboard events; never re-attempt it without a different input mechanism. Full: docs/invariants/hs787.md#hs-1
- [HS-2] Read the "TIME TO ALIGN" IRS state from the ND/PFD `.time-to-align` DOM element, never from `WT_IRS_POS_SET_N` alone, which means position accepted, not alignment complete. Full: docs/invariants/hs787.md#hs-2
- [HS-3] WT787 `boeing-mfd-button` reacts to MOUSE events: `clickElement` must dispatch pointerdown/mousedown/pointerup/mouseup/click, or CDU page keys silently do nothing (LSKs still work, masking it). Full: docs/invariants/hs787.md#hs-3
- [HS-5] A display-only Flight Data sub-panel needs a `BuildPanelControls` entry, even an empty one, or MainForm's panel build early-returns and the panel renders nothing. Full: docs/invariants/hs787.md#hs-5
- [HS-6] Before calling an HS787 readout dead, confirm the aircraft is not in a genuine failure state; several "dead" readouts were correct values during a fuel-exhaustion failure. Full: docs/invariants/hs787.md#hs-6
- [HS-7] APU generator control uses the un-indexed `APU_GENERATOR_SWITCH_SET` (both gens ganged); the per-index `APU_GEN1/2_SWITCH_SET` events are no-ops. Full: docs/invariants/hs787.md#hs-7
- [HS-8] Autobrake steps `INCREASE/DECREASE_AUTOBRAKE_CONTROL` toward the target and reads `AUTO BRAKE SWITCH CB`; `SET_AUTOBRAKE_CONTROL` is a no-op and `AUTOBRAKE CONTROL SWITCH POSITION` is stuck at 0. Full: docs/invariants/hs787.md#hs-8
- [HS-9] Strobe lights use `STROBES_SET`, never `STROBE_LIGHTS_SET` (a no-op on the Asobo-template lighting). Full: docs/invariants/hs787.md#hs-9
- [HS-10] The Community-folder HS787 bridge (HTML patching + injected JS) is removed on both sims; never reinstate the installer: the Coherent transport needs no Community mod and no sim restart. Full: docs/invariants/hs787.md#hs-10
