# iniBuilds A300-600 rules

Loaded when Claude reads matching code. Background: docs/a300.md. Full text of each rule: docs/invariants/a300.md. The displays, MCDUs, tablet and autoflight rules are in a300-displays.md.

- [A300-1] Every map-driven A300 row fires its OWN B: Set event (or the clickspot `PositionEvent` names) through `ExecuteCalculatorCodeUnique` (`A300WritePlan`), never `SetLVar`. A two-position switch's Set FLIPS it whatever the value, so send it only from a KNOWN, differing position (`A300CommandedState`), else refuse aloud. (more: see full) Full: docs/invariants/a300.md#a300-1
- [A300-2] `a300_control_map.json` is GENERATED by `tools/a300-gen` from the aircraft's behavior file, tooltips and checklist: never hand-edit it; regenerate after an iniBuilds update and review with `diff_maps.py`. iniBuilds' files and any decoded copy stay out of the repo. Full: docs/invariants/a300.md#a300-2
- [A300-3] `A300PanelLayout` is the ONLY source of A300 panels: iniBuilds' tree places a control unless `ControlPanels` sends it to its system's panel (`.Systems.cs`); order is `PanelOrder`, `LeadRows`, then the map's `checklist` step; the rest follow, never dropped; names live in `A300PanelLayout.Names.cs`. Guard covers are never rows. (more: see full) Full: docs/invariants/a300.md#a300-3
- [A300-7] Master warning and caution speak only as they come ON (the press writes 0 to the same var). Lamps and the announced levers (`AnnouncedKeys`) speak from `ProcessSimVarUpdate` inside MainForm's mute wrap (`DefAnnounceMuteSets` lists `INI_A300`); a context reset wipes the baselines and `Md11SeedGate` decides the re-seed. (more: see full) Full: docs/invariants/a300.md#a300-7
- [A300-12] `A300FaultLights` (55) stream on their OWN subscriptions, never the batch (it would split the FMA). Collect a change only while `announcer.Suppressed` is false and its light's own Ctrl+M row is ticked ([A300-23]), speak it at batch end as one sentence (`A300LampCallouts`), and name a light from the cockpit node it lights, never its variable alone. Full: docs/invariants/a300.md#a300-12
- [A300-13] `A300EngagementTracker` is silent for MSFSBA's own pick, judged by `A300CommandedState` (2.5 s), never by a cache compare. Its Ctrl+M rows ride `INI_AUTOPILOT_DISCONNECT`/`INI_AUTOTHROTTLE_DISCONNECTED`, registered only to carry the rows; nothing reads their unmeasured values. Full: docs/invariants/a300.md#a300-13
- [A300-20] An autobrake button's label is its lamp (`A300Autobrake`): "Armed" while `INI_AUTOBRAKE_LEVEL` is its level, "Decel" while its `INI_AUTOBRAKE_*_DECEL` is lit, else "Off"; never `INI_autobrake_armed`, which only the button handlers write, so the aircraft's own disarm leaves it 1. Never block a press of the active level (the aircraft disarms it). Full: docs/invariants/a300.md#a300-20
- [A300-21] A TRP button's label is its lamp, `INI_TRP_MODE` == its number (1 TOGA, 2 MCT, 3 CL, 4 CR, 5 AUTO, 6 FLEX TO; `A300Trp`); AUTO stays 5 while `INI_TRP_AUTO_MODE` holds the chosen limit (1, 3, 4), so never read the limit as a lit button. The N1 limit (`INI_THRUST_MAXIMUM_N1`) is read only on GE engines (`INI_IS_PW` 0); PW's TRP shows EPR. Full: docs/invariants/a300.md#a300-21
- [A300-23] An A300 light speaks, and its status box reads On, only as the cockpit lights it: its state AND its bus's light power (`INI_AC/DC_LIGHTS_FAILURE`, 1 = powered; each `A300FaultLights` entry names its bus from the emissive code), decided for the fault and autobrake lights by ONE `A300LampBoard`; an unread input sets no baseline. Full: docs/invariants/a300.md#a300-23
- [A300-24] A300 light changes reach speech only through `A300LampSpeech`: netted per light, a light's first change held `GatherMs` (repeats add none), all held `SettleMs` after a bus's light power flips (`A300LampBoard.PowerFlips`): power and fault flags arrive on separate once-a-second subscriptions, in either order. Never announce a board change directly. Full: docs/invariants/a300.md#a300-24
- [A300-25] A light in `A300PanelLamps` is read through its own cockpit rule (`A300LampRule` over the map's generated `lamps`, [A300-2]) AND its bus's light power; its key streams the rule's first variable on its own subscription with its Ctrl+M row, others come once under `A300_IN_` keys. Never repeat a fault light's variable or an OFF/ON legend. Full: docs/invariants/a300.md#a300-25
- [A300-26] An A300 VHF or ADF transfer switch PICKS the window in use, it never swaps them (VHF 0 and ADF 1 use the first window): every line and read-back names a window active or standby from the transfer switch (`A300Radios`), never from the knob's name, which iniBuilds calls "standby" whatever its role. Full: docs/invariants/a300.md#a300-26
- [A300-28] An A300 light going dark speaks only after `A300LampSpeech.OffHoldMs` steady dark; relit inside it, nothing (the iFly 737's flash filter), except an off before a power change's sentence, which nets in it. A flashing lamp (`A300Lamp.Flashes`: the autoland light) streams every change (`HighFrequency`): once a second aliases its 0.6 s flash to ~3 s. Full: docs/invariants/a300.md#a300-28
