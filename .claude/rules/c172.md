# Cessna 172 Skyhawk rules

Loaded when Claude reads matching code. Background: docs/c172.md. Full text of each rule: docs/invariants/c172.md.

- [C172-1] The main battery is `ELECTRICAL MASTER BATTERY:2`, index 1 the standby; never send `TOGGLE_MASTER_BATTERY` without an index (it flips both). Full: docs/invariants/c172.md#c172-1
- [C172-2] A G1000 switch writes its input event with a value (`SwitchInputEvents`), never a toggle; `AVIONICS_MASTER_n_SET` and `FUEL_SELECTOR_SET` miss this cockpit. Read what it drives (`LIGHT NAV`, not `LIGHT NAV ON`); avionics buses, standby battery and magneto read their input event. Full: docs/invariants/c172.md#c172-2
- [C172-3] A GFC 700 key is one press, `AS1000_AUTOPILOT_<KEY>_PFD` = 1 (`AutopilotKeys`), never K: events. The selected altitude is one `AP_ALT_VAR_INC` then a SimVar write (`ShowSelectedAltitudeDialog`); `AP_ALT_VAR_SET_ENGLISH` ignores its value. Full: docs/invariants/c172.md#c172-3
- [C172-4] A cover's input event TOGGLES it (`CoverInputEvents`): press only after a fresh read differs. `COVER ON:1` is the engine (fitted, no start, autostart included), 2 pitot, 3 static port. Full: docs/invariants/c172.md#c172-4
- [C172-5] The fuel selector reads `FUELSYSTEM JUNCTION SETTING:1` (`FuelSelectorPositions`): 1 Left, 2 Both, 3 Right, measured by tank drain; the input value is one less. Never label it from cockpit order. Full: docs/invariants/c172.md#c172-5
- [C172-6] Never hold the key at START by repeating writes: it springs back in 3.0-3.6 s whatever is sent, and each gap restarts the crank. The Starter is one START plus a backup `StarterBackupMs` later. Full: docs/invariants/c172.md#c172-6
- [C172-7] A breaker's input event is a direct set, 1 Pulled 0 In (`BreakerInputEvents`), and is read from it. ADC, Nav 1, PFD and avionics bus 1's loads are dual-fed: one such breaker alone cuts nothing, by design. Full: docs/invariants/c172.md#c172-7
- [C172-8] Never write the cabin door or its handle (`INSTRUMENT_DOOR_LEFT`, `UNKNOWN_DOOR_HANDLE_1`): it put the pilot outside mid-session. The windows (`AIRCRAFT_DOOR_WINDOW_PILOT`, `AIRCRAFT_DOOR_WINDOW`) are safe direct sets. Full: docs/invariants/c172.md#c172-8
- [C172-9] Take an input event's scale from SimConnect (debug.log), never Coherent's `B:` read: the cabin levers (`Lever`, `QuarterStep`) are percent in one, a fraction in the other. Full: docs/invariants/c172.md#c172-9
- [C172-10] A GMA 1347 key (`AudioKeyInputEvents`, `MicKeys`, `IntercomKeys`) is a momentary push that TOGGLES: push only after a fresh read differs (`SetAudioKeyAsync`), never a direct set or the DA40's by-value write (DA40F-12). Full: docs/invariants/c172.md#c172-10
- [C172-11] The typed course goes to the CDI's source (`SetCourseAsync`, `CourseEventFor`), never through the CRS knob's input event, whose direction is unreliable. Full: docs/invariants/c172.md#c172-11
- [C172-12] The audio rows are spoken by `NoteAudioUpdate` (returns true, own baseline), never the generic announcer: a knock-on of our own COM set stays quiet (`IsComAudioSideEffect`, `ComAudioGraceMs`) yet still moves the baseline. Full: docs/invariants/c172.md#c172-12
- [C172-13] The squawk is BCD16: its key stays `TRANSPONDER_CODE_SET` so MainForm encodes it, and `HandleUIVariableSet` returns false for it; never the generic event path (a plain number). Full: docs/invariants/c172.md#c172-13
- [C172-14] A typed standby goes in whole hertz (`StandbyHz`), each radio swapping through its own event; a frequency out of band is refused aloud (`StandbyRefusal`), never clamped. Full: docs/invariants/c172.md#c172-14
- [C172-15] The transponder mode is TRANSPONDER STATE:1 written directly; Off is listed so a 0 clears the pick, and refused. Ident (`XPNDR_IDENT_ON`) works only On or Altitude: refused aloud in standby, never sent. Full: docs/invariants/c172.md#c172-15
- [C172-16] ELECTRICAL MAIN BUS VOLTAGE and BUS VOLTAGE:n read 0: read ELECTRICAL BUS VOLTAGE by bus name (`C172_MAIN_BUS_VOLTS`, `C172_ESS_BUS_VOLTS`). No battery amps: ELECTRICAL BATTERY LOAD is a magnitude. Full: docs/invariants/c172.md#c172-16
- [C172-17] Warnings and cautions are the G1000's CAS, spoken by the shared CAS watcher; never recompute one from SimVars (said twice). The FMA speaks the modes, so their rows are quiet (`IsAutopilotModeSpokenByFma`, `QuietModesTheFmaSpeaks`); AP and FD keep OFF. Full: docs/invariants/c172.md#c172-17
- [C172-18] An engine reading carries the zone the G1000's panel.xml draws (`CessnaC172Gauges`), never the DA40's bands; green holds both ends, "below/above the green arc" only with an arc beyond, RPM's green top by altitude (`NextRpmArc`). Full: docs/invariants/c172.md#c172-18
- [C172-19] Read an on-request value fresh (`SayFreshAsync`), never from the cache (its last fetch, however old). A cache lookup names only a Continuous, IsAnnounced variable (`Every_cache_lookup_names_a_variable_the_batch_keeps_current`). Full: docs/invariants/c172.md#c172-19
- [C172-20] Every settable switch is Continuous and announced (`AnnouncedSwitch`, `InputEventState`) with a Ctrl+M row; the Starter's key turn (`IsStarterTurnOfTheKey`) and unlisted positions (`IsUnlistedSwitchPosition`) stay quiet. Levers, dimmers, windows are not announced. Full: docs/invariants/c172.md#c172-20
- [C172-21] Output Shift+A/H/S/V are the GFC 700's SELECTED values (`SelectedValueKeys`; MainForm answers only current ones), read fresh, plus the mode when active (`WithActiveMode`) from the cache, so a mode key stays Continuous and announced. Full: docs/invariants/c172.md#c172-21
- [C172-22] Input Ctrl+S sends the FLC speed (`ShowSelectedAirspeedDialog`, `AP_SPD_VAR_SET`, whole knots). The GFC 700 takes any number, so one outside VS1 48 to VNE 163 (`FlcMinKnots`, `FlcMaxKnots`) is refused aloud, never clamped. Full: docs/invariants/c172.md#c172-22
- [C172-23] The speeds (`CessnaC172Speeds`) are the flight model's, from Simplane.getDesignSpeeds(), never the SimVars (`DESIGN SPEED VFE` reads 0, the barber pole 160); manoeuvring speed is the POH's for the weight (`ManoeuvringSpeed`). Full: docs/invariants/c172.md#c172-23
- [C172-24] A `FUEL TANK ... QUANTITY` write sets the tank's TOTAL (28 gal), every read is usable (total - 1.5): the pilot types usable fuel and `TankTotalGallons` adds the 1.5. The sim takes an overfill, so a load outside 0-26.5 is refused aloud (`UsableFuelRefusal`), never clamped; on the ground, propeller stopped (`RefuelBlocker`). Full: docs/invariants/c172.md#c172-24
