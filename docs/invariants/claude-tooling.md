# Claude Code tooling — rules in full

Each section is the complete text of one rule. Its one-line form, under the same ID, is in `.claude/rules/claude-tooling.md`, which Claude Code loads when it reads matching code. Background: [development.md](../development.md), "Claude Code hooks".

## CCT-1

- `.claude/hooks/rules-hook.ps1` runs inside every Claude Code session in this repository, on every contributor's machine (it is registered in the committed `.claude/settings.json`), so a bug in it must never stop work. Every hook mode fails open. The script body sits in one try/catch that exits 0; a mode that cannot parse its input, find a checkout root (a folder holding both `.claude\rules` and a `.git` entry) or read a rule file adds nothing and refuses nothing; and `shell-guard` refuses a command only when it has positively matched one of the command's write targets to a file some rule file covers. An unterminated quote, a target with an unexpanded variable (`$HOME`, `%TEMP%`) and a write made by a script (Python, `dotnet`) are all allowed: the guard is a net, and CORE-16's instruction still covers what it cannot see. `MSFSBA_RULES_HOOK=off`, set before Claude Code starts, silences every hook mode on that machine. Added 2026-10-08 with the hook.

## CCT-2

- The hook decides which rule files load for a path with its own copy of the guard test's matching. `Convert-GlobToRegex` mirrors `ClaudeContextBudgetTests.GlobRegex`: `*` stays within one path segment, `**/` spans any number of segments, a trailing `**` covers everything below, `?` is one character, everything else is escaped, and the pattern is anchored and case-sensitive. `Split-FrontMatter` mirrors `SplitFrontMatter`: front matter only when the file starts with `---` and a line feed, and `paths:` items as `- "<glob>"` lines. If the two drift, the hook adds rules the guard never budgeted, or misses rules the guard counts as loading. `ClaudeRulesHookTests.For_machine_output_matches_the_guard_matcher_for_every_repo_file` runs the hook's `for -Machine -Stdin` over every file in the repository and compares the result with the guard's matcher; change both together, never one. Claude Code's own matcher is a third implementation: the guard assumes it behaves the same, and the live checks in docs/development.md confirm that for the patterns this repository uses.

## CCT-3

- Hooks load when a Claude Code session starts, so only a fresh session shows the effect of a change to `.claude/settings.json`; a running session keeps the hooks it started with. A filter can also fail silently. Measured on 2026-10-08 with Claude Code 2.1.252 in headless sessions: `Read(//**/.claude/worktrees/agent-*/**)` matched a worktree subagent's read and nothing in the main conversation, while the relative form `Read(**/.claude/worktrees/agent-*/**)` matched nothing; neither `Edit(//**/...)` nor `Write(//**/...)` matched a Write, so the read mode runs unfiltered on Write and NotebookEdit and exits at once outside agent worktrees; `Bash(cat >*)` and `Bash(echo *>*)` never matched, because redirects are stripped before matching, so the shell guard also starts on a plain `cat` or `echo` (about 0.2 s) and allows it; `Bash(git diff*)` matched a bare `git diff`, and `Bash(git -C * diff*)` the `-C` form. `ClaudeRulesHookTests.Settings_register_the_pinned_hooks` pins the list so that a filter change is deliberate: run the live checks in docs/development.md in a fresh session, then update the pinned list.

## CCT-4

- `ClaudeContextBudgetTests`' limits (CLAUDE.md at 25,000 characters and 200 lines, a rule line at 400, a rule file at 12,000, and any one file's rules at 30,000) were set by the lean-CLAUDE.md design (#265, `docs/design/2026-09-30-lean-claude-md-design.md`) for adherence; they are not Claude Code's, which loads a CLAUDE.md of up to 4 MiB in full. When one bites, take the remedies its failure message lists, in order: shorten lines; mirror the few rules a file needs instead of globbing a whole area onto it; split a large area file; retire rules whose code is gone. Raising a cap is the owner's decision, never a change made to get a PR green.
