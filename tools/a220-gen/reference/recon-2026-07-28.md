## R5 — FMS input path (**PROVEN end-to-end, 2026-07-29**)
The Marketplace package is UNENCRYPTED on disk — `ModelBehaviorDefs\Synaptic\A220\`
is readable and is the input-event authority (the JS bundles are pure renderers:
zero H:/L:/scratchpad strings in 4 MB of instrument.js).
- **MKP keys** = `H:A220_KBD_{ID}_{1|2}` (1=left, 2=right; fired as `1 (>H:…)`).
  IDs: `A`-`Z`, `0`-`9`, `DOT SLASH SPACE PLUS_MINUS CLEAR ENTER`, cursor
  `UP DOWN LEFT RIGHT PREV NEXT`, quick-access `CAS MSG ROUTE DIR DEP`, formats
  `MAP FMS CNS CHKL SYN DATA`. EXEC/CNCL are `L:A22X Flight Plan Execute/Cancel`
  (write 1; consumed). **CTP** = `H:A220_CTP_{ID}_{1|2}` (`WXR TERR TFC WX TUNE
  IDENT ACROSS INDB_L INDB_R MAP FMS CNS CHKL SYN DATA LSK1-4 RSK1-3` + knobs
  `H:A220_CTP_TUNE_LARGE/SMALL_{n}_INC/DEC`, `H:A220_CTP_RANGE_{n}_INC/DEC`).
  **CCP** = `H:A220_CCP_{DSPL_UPR|DSPL_LWR|MENU}_{n}` + `H:A220_DSK_LARGE/SMALL_{n}_INC/DEC`.
  Other: `H:A220_ISI_UP/DOWN/MENU`, `H:A220_RSP_INHIB_L/R`, `H:A220_FCU_CPDLC_*`.
- MobiFlight-fired H: events reach the views (hooked `Coherent.on('OnInteractionEvent')`
  in the MKP view: `["A220_KBD_A_1"]` arrived) and the aircraft consumes them:
  typed EGLL appeared on the MKP scratchpad view.
- **Field commit is a synthetic mouse click** on the field's VALUE node in the
  DisplayUnits view (full pointerdown/mousedown/pointerup/mouseup/click at the
  node's screen coords; the CCP cursor is a real mouse there — `virtualmouse` IMG).
  Proven: EGLL committed into FPLN INIT ORIGIN, mode ACT→MOD, EXEC/CNCL soft keys
  appeared; `1 (>L:A22X Flight Plan Cancel)` reverted it.
- MKP cursor keys / DSK knob events did NOT move any visible focus (the 54×54 cyan
  cursor rect stays parked at -100,-100) — clicks are the commit path, not ENTER.
- Layout facts: value node sits ~34 px BELOW its gray label at the same x; labels
