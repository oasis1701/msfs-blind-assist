## Brakes

Brake pedal / autobrake input (`BrakeVars`, feeds `BrakeControls`):

| Event | Description |
|---|---|
| `BRAKES` | Applies brakes; ramps the commanded brake pressure up over time while held/repeated, and releases it back down once no longer pressed. |
| `BRAKES_LEFT` | Applies the left brake; in this implementation it ramps the same shared commanded brake pressure as `BRAKES`. |
| `BRAKES_RIGHT` | Applies the right brake; in this implementation it ramps the same shared commanded brake pressure as `BRAKES`. |
| `PARKING_BRAKES` | Toggles the parking brake. |
| `PARKING_BRAKE_SET` | Sets the parking brake to an explicit on/off value. |
| `AUTOBRAKE_DISARM` | Disarms the autobrake. |
| `AUTOBRAKE_HI_SET` | Selects the HI autobrake setting. |
| `AUTOBRAKE_MED_SET` | Selects the MED autobrake setting. |
| `AUTOBRAKE_LO_SET` | Selects the LO autobrake setting. |
| `INCREASE_AUTOBRAKE_CONTROL` | Steps the autobrake selector up one setting. |
| `DECREASE_AUTOBRAKE_CONTROL` | Steps the autobrake selector down one setting. |
| `SET_AUTOBRAKE_CONTROL` | Sets the autobrake selector directly to a given level. |


## Electronic Flight Control System (EFCS)

### Pitch/Roll/Rudder/Spoiler Inceptor Transformers (RVDT)

Each `RotaryTransformer` instance converts a trio of simulator input events (an absolute axis-set event, plus increment/decrement step events) into a normalized 0–1 (or -1–1) position. There are two instances: pitch and roll.

| Event | Description |
|---|---|
| `AXIS_ELEVATOR_SET` | Sets the pitch sidestick input axis directly (absolute), used to drive the elevator inceptor position. |
| `ELEVATOR_UP` | Steps the pitch input toward nose-up by a fixed amount per tick while received. |
| `ELEVATOR_DOWN` | Steps the pitch input toward nose-down by a fixed amount per tick while received. |
| `AXIS_AILERONS_SET` | Sets the roll sidestick input axis directly (absolute), used to drive the aileron inceptor position. |
| `AILERONS_RIGHT` | Steps the roll input toward right by a fixed amount per tick while received. |
| `AILERONS_LEFT` | Steps the roll input toward left by a fixed amount per tick while received. |

`RudderTransformer` (rudder pedals):

| Event | Description |
|---|---|
| `AXIS_RUDDER_SET` | Sets the rudder pedal input axis directly (absolute). |
| `RUDDER_RIGHT` | Steps the rudder pedal input toward right by a fixed amount per tick while received. |
| `RUDDER_LEFT` | Steps the rudder pedal input toward left by a fixed amount per tick while received. |
| `RUDDER_AXIS_PLUS` | Sets the rudder pedal input axis directly (positive/inverted axis convention). |
| `RUDDER_AXIS_MINUS` | Sets the rudder pedal input axis directly (negative/inverted axis convention). |

`SpoilerTransformer` (spoiler/speedbrake lever):

| Event | Description |
|---|---|
| `SPOILERS_ARM_OFF` | Consumed (masked) to prevent the stock spoiler-arm-off event from affecting the default flight model; not otherwise used. |
| `SPOILERS_ARM_ON` | Consumed (masked) to prevent the stock spoiler-arm-on event from affecting the default flight model; not otherwise used. |
| `SPOILERS_ARM_SET` | Consumed (masked) to prevent the stock spoiler-arm-set event from affecting the default flight model; not otherwise used. |
| `SPOILERS_ARM_TOGGLE` | Consumed (masked) to prevent the stock spoiler-arm-toggle event from affecting the default flight model; not otherwise used. |
| `AXIS_SPOILER_SET` | Sets the spoiler lever input axis directly (absolute). |
| `SPOILERS_SET` | Sets the spoiler lever input axis directly (absolute, alternate event). |
| `SPOILERS_DEC` | Steps the spoiler lever input down by a fixed amount when received. |
| `SPOILERS_INC` | Steps the spoiler lever input up by a fixed amount when received. |
| `SPOILERS_OFF` | Sets the spoiler lever fully retracted. |
| `SPOILERS_ON` | Sets the spoiler lever fully deployed. |
| `SPOILERS_TOGGLE` | Toggles the spoiler lever between fully retracted and fully deployed. |

Elevator/aileron/rudder trim switches (`TrimSwitch`, one instance each for pitch, aileron, and rudder trim):

| Event | Description |
|---|---|
| `AXIS_ELEV_TRIM_SET` | Consumed (masked) to sink the stock elevator-trim axis-set event; its value is not used, only the pitch trim switch inputs drive trim. |
| `ELEV_TRIM_DN` | Received when the pitch trim switch is moved nose-down; drives the trim rate input this tick. |
| `ELEV_TRIM_UP` | Received when the pitch trim switch is moved nose-up; drives the trim rate input this tick. |
| `AILERON_TRIM_SET_EX1` | Consumed (masked) to sink the stock aileron-trim axis-set event; its value is not used, only the aileron trim switch inputs drive trim. |
| `AILERON_TRIM_RIGHT` | Received when the aileron trim switch is moved right; drives the trim rate input this tick. |
| `AILERON_TRIM_LEFT` | Received when the aileron trim switch is moved left; drives the trim rate input this tick. |
| `RUDDER_TRIM_SET_EX1` | Consumed (masked) to sink the stock rudder-trim axis-set event; its value is not used, only the rudder trim switch inputs drive trim. |
| `RUDDER_TRIM_RIGHT` | Received when the rudder trim switch is moved right; drives the trim rate input this tick. |
| `RUDDER_TRIM_LEFT` | Received when the rudder trim switch is moved left; drives the trim rate input this tick. |

Autopilot disconnect / sidestick priority button (`Button`):

| Event | Description |
|---|---|
| `AUTOPILOT_OFF` | Autopilot disconnect / priority button press; triggers the AP-disengage and sidestick priority logic. |
| `AUTOPILOT_DISENGAGE_SET` | Alternate autopilot-disengage event consumed by the same priority button logic. |

## Flight Control Panel (FCP)

The autopilot/flight-guidance control panel: physical panel state (brightness, backlight, knob/button inputs) plus flight guidance mode annunciations.

| Event | Description |
|---|---|
| `AP_MASTER` | Toggles the autopilot master on/off. |
| `AUTO_THROTTLE_ARM` | Arms the autothrottle. |
| `AP_SPD_VAR_INC` | Increments the selected speed (knob right). |
| `AP_SPD_VAR_DEC` | Decrements the selected speed (knob left). |
| `AP_MANAGED_SPEED_IN_MACH_TOGGLE` | Toggles managed speed units between knots and Mach. |
| `HEADING_BUG_INC` | Increments the heading bug (knob right). |
| `HEADING_BUG_DEC` | Decrements the heading bug (knob left). |
| `HEADING_BUG_SET` | Syncs the heading bug to the current heading. |
| `AP_HDG_HOLD` | Engages HDG (heading select) mode. |
| `AP_NAV1_HOLD` | Engages LNAV/NAV mode. |
| `AP_APR_HOLD` | Engages APPR (approach) mode. |
| `AP_MAX_BANK_ANGLE_SET` | Toggles half-bank mode. |
| `AP_ALT_VAR_INC` | Increments the selected altitude (knob right). |
| `AP_ALT_VAR_DEC` | Decrements the selected altitude (knob left). |
| `FLIGHT_LEVEL_CHANGE` | Engages FLC (flight level change) mode. |
| `AP_ALT_HOLD` | Engages altitude hold mode. |
| `AP_VS_VAR_INC` | Increments the selected vertical speed (knob up). |
| `AP_VS_VAR_DEC` | Decrements the selected vertical speed (knob down). |
| `AP_VS_HOLD` | Engages vertical speed mode. |
| `AP_ATT_HOLD` | Engages flight-path-angle/pitch-hold mode. |

## VHF Radio (COM/NAV/Marker Beacon)

`{id}` below is the radio instance identifier used to build a family of tuning key events: `COM1`/`COM2`/`COM3` for the COM radios, `NAV1`/`NAV2` for the NAV radios. `{N}` is the matching numeric index (1-3 for COM, 1-2 for NAV).

| Event | Description |
|---|---|
| `COM_STBY_RADIO_SWAP`<br/>`COM1_RADIO_SWAP`<br/>`COM2_RADIO_SWAP`<br/>`COM3_RADIO_SWAP` | Swaps the active and standby frequencies (COM1 also accepts `COM_STBY_RADIO_SWAP`). |
| `COM_RADIO_SET`<br/>`COM2_RADIO_SET`<br/>`COM3_RADIO_SET` | Sets the active frequency from a BCD-encoded value. |
| `COM_RADIO_SET_HZ`<br/>`COM2_RADIO_SET_HZ`<br/>`COM3_RADIO_SET_HZ` | Reads and writes the active frequency in raw Hz: accepts external sets and re-sends the radio's current active frequency each tick. |
| `COM_RADIO_WHOLE_INC`<br/>`COM2_RADIO_WHOLE_INC`<br/>`COM3_RADIO_WHOLE_INC` | Increments the whole MHz digit of the active frequency. |
| `COM_RADIO_WHOLE_DEC`<br/>`COM2_RADIO_WHOLE_DEC`<br/>`COM3_RADIO_WHOLE_DEC` | Decrements the whole MHz digit of the active frequency. |
| `COM_RADIO_FRACT_INC`<br/>`COM2_RADIO_FRACT_INC`<br/>`COM3_RADIO_FRACT_INC` | Increments the fractional (kHz) digit of the active frequency. |
| `COM_RADIO_FRACT_INC_CARRY`<br/>`COM2_RADIO_FRACT_INC_CARRY`<br/>`COM3_RADIO_FRACT_INC_CARRY` | Increments the fractional digit of the active frequency and carries into the whole MHz digit. |
| `COM_RADIO_FRACT_DEC`<br/>`COM2_RADIO_FRACT_DEC`<br/>`COM3_RADIO_FRACT_DEC` | Decrements the fractional (kHz) digit of the active frequency. |
| `COM_RADIO_FRACT_DEC_CARRY`<br/>`COM2_RADIO_FRACT_DEC_CARRY`<br/>`COM3_RADIO_FRACT_DEC_CARRY` | Decrements the fractional digit of the active frequency and carries into the whole MHz digit. |
| `COM_STBY_RADIO_SET`<br/>`COM2_STBY_RADIO_SET`<br/>`COM3_STBY_RADIO_SET` | Sets the standby frequency from a BCD-encoded value. |
| `COM_STBY_RADIO_SET_HZ`<br/>`COM2_STBY_RADIO_SET_HZ`<br/>`COM3_STBY_RADIO_SET_HZ` | Reads and writes the standby frequency in raw Hz: accepts external sets and re-sends the radio's current standby frequency each tick. |
| `NAV1_STBY_SET`<br/>`NAV2_STBY_SET` | Sets the standby frequency from a BCD-encoded value. |
| `NAV1_STBY_SET_HZ`<br/>`NAV2_STBY_SET_HZ` | Reads and writes the standby frequency in raw Hz: accepts external sets and re-sends the radio's current standby frequency each tick. |
