title: SimVars
description: |
  Index of all simulator variables (L-Vars) that the A220 reads and writes, organized by system.
  These can be used to read and modify the aircraft state's using external applications.
---

## Auxiliary Power Unit (APU)

| Variable | Unit | Description |
|---|---|---|
| `L:A22X APU RPM` | Number | Writes the APU's rotational speed as a percentage of maximum (0-100), used for cockpit indication and by other systems (e.g. bleed air, electrical) to gate on APU speed. |
| `L:A22X APU Starter` | Bool | Writes whether the APU starter/starter-generator is currently engaged and cranking the APU. |
| `L:A22X APU Door` | Percent over 100 | Writes the APU inlet/exhaust door position, from 0 (closed) to 1 (fully open), used to drive the door animation. |

## Bleed Air System

### Anti-Ice

| Variable | Unit | Description |
|---|---|---|
| `STRUCTURAL ICE PCT` | Percent over 100 | Reads the simulator's structural ice accumulation on the airframe, used to drive the wing/structural ice detector state machine. |
| `STRUCTURAL DEICE SWITCH` | Bool | Reads whether the simulator's structural (wing) anti-ice switch is currently on. |

### Pressurization / Trim Air (Integrated Air System Controllers)

| Variable | Unit | Description |
|---|---|---|
| `L:A22X Cockpit Trim Air Flow` | Number | Writes the trim air mass flow being delivered into the cockpit by the trim air system. |
| `L:A22X Fwd Cabin Trim Air Flow` | Number | Writes the trim air mass flow being delivered into the forward cabin. |
| `L:A22X Aft Cabin Trim Air Flow` | Number | Writes the trim air mass flow being delivered into the aft cabin. |
| `L:A22X Fwd Cargo Trim Air Flow` | Number | Writes the trim air mass flow being delivered into the forward cargo compartment. |
| `L:A22X Left Pack Flow` | Number | Writes the air mass flow output of the left air conditioning pack. |
| `L:A22X Right Pack Flow` | Number | Writes the air mass flow output of the right air conditioning pack. |

Note: `L:A22X IASC {Cockpit,Fwd Cargo,Fwd Cabin,Aft Cabin} {P,I}` (the PID gains for each zone's duct temperature controller) are defined in code but their `#[var(...)]` attributes are currently commented out (`bleed/mod.rs:647-661`), so they are not presently registered with the simulator.

### Ram Air & Recirculation

| Variable | Unit | Description |
|---|---|---|
| `L:A22X Ram Air` | Bool | Reads whether the ram air valve is commanded open (used for outflow/pressurization backup). |
| `L:A22X Recirc Fan Speed` | Percent over 100 | Writes the commanded speed of the cabin air recirculation fan. |

## Display Units (DU)

The A220 has 5 display units; `{N}` is the DU number (1-5).

| Variable | Unit | Description |
|---|---|---|
| `A22X DU{N} Data` | — | Sent to display unit `{N}`'s JS instrument bundle: its full rendered state (power state, brightness, reversion status). |
| `L:A22X DU{N} Backlight` | Number | The backlight brightness commanded to display unit `{N}`. |
| `L:A22X L Inboard Brightness` | Number | The brightness knob position for the left inboard display's backlighting. |
| `L:A22X L Outboard Brightness` | Number | The brightness knob position for the left outboard display's backlighting. |
| `L:A22X R Inboard Brightness` | Number | The brightness knob position for the right inboard display's backlighting. |
| `L:A22X R Outboard Brightness` | Number | The brightness knob position for the right outboard display's backlighting. |
| `L:A22X Lower Brightness` | Number | The brightness knob position for the lower (EICAS) display's backlighting. |

## Doors

| Variable | Unit | Description |

| `INTERACTIVE POINT OPEN:{N}` | Percent over 100 | How far open the door/exit at interactive point `{N}` is. |
| `L:A22X Cockpit Door Open` | Bool | Whether the cockpit door is open. |
