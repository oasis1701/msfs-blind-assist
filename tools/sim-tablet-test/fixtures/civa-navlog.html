ABOUT THE VIRTUAL NAVIGATOR

The virtual navigator bridges the simulator's flight plan with the aircraft's Delco Carousel IV-A (CIVA) inertial navigation system (INS). When you import a route, the system reads the planned waypoints and converts them into the latitude/longitude coordinate format the INS requires. The origin, enroute fixes, and destination are extracted automatically so that no manual coordinate entry is necessary.

Because the CIVA INS can only hold 9 waypoints at a time, routes longer than 9 waypoints are loaded in segments using a sliding window. When Auto-Sync is enabled, the system automatically programs the next batch of waypoints as the aircraft nears the end of the current set. It is also possible to manually send any individual waypoint to a specific INS slot, or use Direct-To to skip ahead in the route.

The import procedures toggle allows SID and STAR waypoints to be included in the route. However, the INS cannot fly all modern procedure leg types such as holds, vector legs, and radius-to-fix turns. These legs are simplified or omitted during import. When this happens, the Warnings button appears so any removed or simplified waypoints can be reviewed.
