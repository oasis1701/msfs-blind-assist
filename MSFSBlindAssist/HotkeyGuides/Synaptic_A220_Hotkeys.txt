Tip: Press the same bracket key again to cancel a mode you activated by accident.


HOW THIS AIRCRAFT IS READ

The A220's systems are read from the aircraft's own data link (the same data its
displays draw): crew alerting messages, gear, doors, engine start, IRS alignment,
the speed bugs, the transponder and both altimeters. If that link is not up
(the simulator still loading, the displays unpowered), readouts say "not
available" rather than guess.


OUTPUT MODE - Press right bracket to activate

  Shift+S    Read selected speed (FMS or manual), with the autothrottle mode

THE PANELS - WHAT IS NEW FOR A FULL FLIGHT

Transponder panel: Transponder Mode (AUTO, STBY, TA/RA, TA ONLY, ALT ON,
ALT OFF), TCAS Altitude Limit (refused while the mode is AUTO, as the
aircraft does), Transponder Code (type four digits, press Enter), Ident and
Set Flight ID. Each change is read back from the transponder; a change it
did not take is said.

Gear and Brakes: the Autobrake combo is the selector's real scale - RTO, OFF,
LO, MED, HI. It is moved one detent at a time and checked after each; a
detent the aircraft refuses is said ("Autobrake LO not available on the
ground - still OFF"). The panel's status lists each gear and the brake
temperatures.

Utilities: Doors lists every door and slide; IRS shows alignment and the
time to navigation. Doors, gear, IRS alignment and engine starts are also
announced as they change (each muted in Ctrl+M).

Take-off: "Rotate" is called at VR from the PFD's own speed bugs. The
aircraft calls V1 itself. If you start a take-off roll with V1 or VR not
set you hear "V-speeds not set" once, and Rotate is not called.
