The Select Destination Runway window now opens with your arrival airport already
filled in and its runways loaded. It uses the destination you set earlier, or else your
flight plan's arrival airport, and never a different airport from the one the Landing
Exit Planner opens on. The filled-in code is selected, so typing a different ICAO
replaces it. Press Enter or Tab to move into the runway list with your planned runway
highlighted. If that runway is not in the airport's list, BA tells you instead of
quietly picking the first one. If the airport cannot be found, BA now says so out
loud, both when the window opens and when you type a code. Pressing Enter when there
are no runways to choose repeats the reason instead of beeping. The status text is
now a read-only box in the tab order, so your screen reader can reach it.
