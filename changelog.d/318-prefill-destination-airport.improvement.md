The Select Destination Runway window now opens with your arrival airport already
filled in and its runways loaded: the destination you set earlier, or otherwise your
flight plan's arrival — the same choice the Landing Exit Planner makes, so the two
windows always open on the same airport. The filled-in code is selected, so typing a
different ICAO replaces it. Pressing Enter (or Tab) moves into the runway list with
your planned runway highlighted, and you are told when that runway is not in the
airport's list instead of silently getting the first one. The window's status text
(runways found, airport not found) is now a read-only box in the tab order, so your
screen reader can reach it.
