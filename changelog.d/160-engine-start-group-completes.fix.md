The First Officer's Engine Start checklist group can now complete when you start the engines
yourself — from the MSFSBA panel or in the cockpit — instead of only when you run the flow.
The start-switch items had no way to tick themselves, so the group stayed stuck part-done
however the engines were started; they now tick once the engine is actually running, and
stay ticked for the rest of the flight. Affects the PMDG 737, PMDG 777 and iFly 737 MAX8.
