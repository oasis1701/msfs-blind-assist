A new File > Sim Performance window shows what the sim's own developer FPS display shows a
sighted pilot: the frame rate and simulation rate, and the simulator's CPU, memory, GPU load
and video memory. One value per row; arrow to the row you want and it re-reads whenever the
value changes, while the other rows stay quiet. It updates itself every second, so there is no
refresh button; Escape closes. The
sim's internal per-thread timings and its "limited by" verdict are not available from outside
the sim, so they are not shown.
