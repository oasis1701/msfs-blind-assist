Fenix A320: BA now tells you when the MobiFlight WASM module is missing. About a minute
after connecting you hear "MobiFlight calculator path unavailable. Some cockpit controls
may not respond.", and a typed FCU value then answers, for example, "Altitude not set:
MobiFlight module not responding." Before, the FCU and baro knobs silently did nothing and
a typed altitude said "Altitude set to 100, not 25000."

If you fly both simulators, check that the module is in the Community folder of each:
MSFS 2020 and MSFS 2024 keep separate ones.
