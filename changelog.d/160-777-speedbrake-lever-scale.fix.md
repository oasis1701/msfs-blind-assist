On the PMDG 777, arming the speedbrake for landing now works. The lever position was being read as a detent number when it is really a 0-100 position — ARMED reads 50 on this aircraft — so the Landing flow armed the lever and then told you it had skipped the step, and ticking "Speedbrake: ARMED" by hand armed it and immediately un-ticked itself with "Unable to complete". Both now recognise the armed lever. The flow also leaves a speedbrake you have already raised alone instead of clicking ARM and retracting it. The detent values were measured on a real aircraft: PMDG's own SDK documentation gives the wrong number for ARMED.
