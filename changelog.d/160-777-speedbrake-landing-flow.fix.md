The PMDG 777 no longer arms the speedbrake during the approach setup — far too early. There is now a Landing flow that arms it and reminds you to set the missed approach altitude, and ticking "Speedbrake: ARMED" on the Landing checklist actually arms the lever, which it never did before. Completing Approach Setup also used to force-check the entire Landing checklist — gear down, flaps set, everything — the moment you finished setting your altimeters, long before any of it was true; that now only happens when the Landing flow itself completes, which is when it should.
