A First Officer flow no longer checks off a step it could not do. When a step fails the flow says so — "Skipping: Speedbrake: ARMED" — but a moment later, when the flow finished, it used to tick that item anyway along with the rest of the section and freeze it there for the rest of the flight, so the checklist told you the switch was set when it never moved and could never correct itself. The rest of the section still completes normally, and if you set the switch by hand afterward the item now ticks itself instead of staying stuck. Separately, if you ticked an item by hand and its action did not take, the tick used to quietly undo itself with nothing said; you now hear "Unable to complete" and the item's name. Affects every aircraft with First Officer support.
