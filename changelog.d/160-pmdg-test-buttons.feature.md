The PMDG 737 and 777 panels have new test buttons. On both, a Weather Radar panel under
Pedestal has a Weather Radar Test button. It runs the predictive windshear self-test: you
hear "Monitor radar display" followed by the windshear aural, and the radar is left back
in WX mode afterwards. On the 737's Forward Panel, GPWS now has a GPWS System Test (Long)
button beside the short test. It holds the button long enough for the extended callout
sequence. A new Warning Tests panel on the 737 Overhead holds the stick shaker and
overspeed clacker test switches, one of each per side. Press a switch once to start the
warning and again to stop it. It is also released automatically if you change aircraft.
