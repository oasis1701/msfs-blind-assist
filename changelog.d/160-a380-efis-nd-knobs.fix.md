The A380 navigation display mode and range knobs now actually move. Setting them from a panel or letting the First Officer set them wrote a value the aircraft overwrites every frame, so the display never changed — and because the First Officer then checked its work, it announced "Unable to complete: EFIS mode ARC" and "EFIS range 40" on every cockpit preparation and approach. Both knobs are now turned the way the cockpit turns them. The range list also had the wrong numbers behind it, which would have selected an airport-zoom range instead of the one you picked.
