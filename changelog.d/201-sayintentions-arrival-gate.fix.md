The SayIntentions taxi-route import no longer sends you to a runway after you land. When SayIntentions had assigned an arrival gate, pressing the import key could still build a confident route to the runway you had just vacated — either because the clearance mentioned your landing runway, or because this scenery names the stand differently and nothing matched. On an arrival with an assigned gate the import now only ever routes to a gate, and when the scenery genuinely has no matching stand it says so by name and asks you to pick the gate in Taxi Assist instead of guessing. Departures are unchanged.
