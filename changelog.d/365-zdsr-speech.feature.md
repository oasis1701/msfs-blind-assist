MSFS Blind Assist now speaks through ZDSR (Zhengdu Screen Reader, 争渡读屏) when ZDSR is your screen reader,
in ZDSR's own voice, and shows each announcement on your braille display for a moment. Before, a ZDSR user
heard the Windows voice instead. A key press stops the speech just as it stops ZDSR's own. If ZDSR closes
while you fly, announcements switch to Windows speech within about a second and come back to ZDSR when it
is running again. NVDA, if it is running too, still comes first. To keep the Windows voice with ZDSR,
choose SAPI on the Announcements tab of Settings. That tab names ZDSR when it finds it, says why when ZDSR
is running but cannot be used (not licensed, or too old), and its status line is now a read-only box you
can reach with Tab. Opening Settings no longer switches JAWS users to the Windows voice.
