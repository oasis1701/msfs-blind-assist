Typed values now accept either a comma or a period as the decimal point, whatever language
Windows is set to. "29,92" and "29.92" both set the altimeter, and "0,82" and "0.82" both
set Mach 0.82. Before, a comma could be refused or misread: on the PMDG 737 and 777 a Mach
of "0,85" set 85 knots, and on the HS787 and PMDG 777 an FPA of "-2,5" set -25 feet per
minute. A number with a thousands separator, such as "10,000", is now refused instead of
being guessed at; type it as 10000.
