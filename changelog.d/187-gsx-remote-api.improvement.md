Access GSX now talks to GSX through its built-in remote interface instead of reading the in-sim menu indirectly, so service status, the menu and GSX's settings arrive as real data — they appear sooner and no longer misread when GSX rewords a message. Selecting your gate is now a single request to GSX rather than a walk through its menus, and it tells you which stand GSX actually prepared — or that it prepared none — instead of leaving you to find out on arrival. This needs GSX 4.0.8 or newer; on an older build, MSFS Blind Assist now says so instead of appearing to do nothing.
