Location Info (Shift+L) is now one table of places you can search and filter, instead of eight
text boxes. Pick which kinds of place to show in a tree (towns, airports, islands, lakes and so
on), search by name around you or the whole world, and move through the results cell by cell.
Any place can become the point the window looks around from, be tracked in a slot, or have its
coordinates copied. Output C can name the nearest place of the kinds you pick, for example the
nearest island or peak. The location data needs downloading again once.
