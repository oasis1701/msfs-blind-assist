Typed values apply on Enter, and the Set buttons beside them are gone, one Tab stop fewer each.
This covers every panel's typed fields (radio standby frequencies, the squawk, FCU values,
minimums) and every Set window: the FCU and altimeter windows on the FlyByWire A320 and A380
and the Fenix A320, the PMDG 737's NAV radios window, and the value windows on the other
aircraft. Enter already did exactly what the button did, with the same checks and
confirmations. Cancel and Close stay, as do the push, pull and mode buttons. In the
altimeter windows, Enter now applies only from the value box itself, not from the Mode or
Unit list.
