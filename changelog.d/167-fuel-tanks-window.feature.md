New **Fuel Tanks window** on output **Alt+U**: every tank the aircraft has, live, with pounds and kilograms on each line and a total at the bottom. Type a tank's first letter to jump straight to it — "c" for Centre, "o" for Outer — so checking one tank is open, one letter, done. Tanks that come in symmetric pairs share a line, which makes an imbalance check a single read. Wired for the FlyByWire A380 and both PMDG jets so far; other aircraft say so when you open it.
