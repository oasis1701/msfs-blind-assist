The Landing Exit Planner no longer offers a single exit on a runway where the scenery marked
only one hold short line. KJFK runway 13L listed only taxiway V, while runway 31R, the other
end of the same runway, listed thirteen. The planner now also lists the exits the scenery left
unmarked, so 13L offers V, W, D, DB, the high-speed exit ZA, E, Y and YA. About 580 runway
ends gain exits this way in the MSFS 2024 database and about 650 in the MSFS 2020 one, and no
exit that was already listed changes.
